# 📚 GyanVerse.AI

An AI-powered study assistant that transforms notes into an interactive learning experience using OCR and Retrieval-Augmented Generation (RAG).

## ✨ Features

- 📸 Scan handwritten and printed notes
- 🔍 Extract text using EasyOCR
- 🧠 AI-powered question answering using RAG
- 📖 Search through your notes instantly
- 🎨 Clean and responsive web interface
- ⚡ Fast semantic retrieval using vector embeddings

## 🛠️ Tech Stack

- Python
- Flask
- EasyOCR
- LangChain
- FAISS
- Google Gemini API
- HTML
- CSS
- JavaScript

```bash

cd Gyanverse-AI

pip install -r requirements.txt

python app.py
```
